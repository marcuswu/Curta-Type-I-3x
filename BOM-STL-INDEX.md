# Printable parts by BOM item

This index connects the item numbers in the [original bill of materials (BOM)](https://docs.google.com/spreadsheets/d/16EJePozXW-uC6UFISzyT2eMk7c8wh6v-EP5L1U8fzfM/edit?usp=sharing) to the STL files and [assembly manual](Manual/Curta%20Build%20Manual.pdf).

- **Qty** is the total needed for one calculator, not necessarily the number of objects contained in an STL. Check the imported model before making copies.
- **Manual page** refers to the numbered PDF page. The matching original STL folder number is one less (for example, folder 31 corresponds to PDF page 32).
- Print notes below are copied from the BOM and are not complete slicer profiles. Consult the original BOM for non-printed hardware, tooling, sourcing and any updates. Some original notes are incomplete.
- Item 78 is only needed when printing the step drum in separate upper and lower parts. The [carry lever spring tool](STLs/Tools/carry%20lever%20spring%20tool.stl) is listed separately from the BOM.
